icsmoi is a visual node-graph tool for building force-feedback (FFB) profiles
for Microsoft Flight Simulator, and a small runtime app that plays those
profiles on your hardware in real time. This manual assumes no coding
knowledge — everything you need to install and use icsmoi is here.
